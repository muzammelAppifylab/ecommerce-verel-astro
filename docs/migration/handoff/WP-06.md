# WP-06 · Journal: hand-off

Branch `wp/WP-06` (from `wave0`). Port of VAREL `worker/routes/{posts,admin/posts}.ts`,
`src/pages/{Blog,BlogCategory,BlogPost}.tsx`, `src/pages/journal/*`, `src/pages/admin/journal/*`.

## What was ported

### API
- `src/server/routes/posts.ts` (`postRoutes`, `/site-api/posts`):
  `GET /` → `Post[]` newest first (`?category=` slug, English name or translated name; `?limit=1–100`,
  default 100; bad limit → 422 `fields.limit`; unknown category → `[]`), `GET /categories`
  (`{name, count, label}` by latest post, from a bounded 100-row scan), `GET /sitemap`
  (`/journal/<slug>/` with `updatedAt` + `/journal/category/<slug>/`), `GET /feed` (20 newest, source
  language), `GET /:slug` → `PostDetail` + related (same category first, then newest, max 3), with
  translated `seoTitle`/`seoDescription` and `updatedAt`. Public cache `max-age=300` with `Vary` on
  the language inputs (feed/sitemap 3600); 404 never cached; impossible slugs 404 without a query.
  Exports `publishedWhere`, `loadPostTr` (WP-08 search can reuse them).
- `src/server/routes/admin/posts.ts` (`postsAdmin`, `/site-api/manage/posts`): list (`q` words AND,
  `status` multi, `category` insensitive, `sort` over `title|category|status|publishedAt|updatedAt`,
  keyset `CursorPage`; `publishedAt` keyset is hand-written with nulls last both ways), get, create
  (default slug from title, 409 `slug_taken` + `fields.slug`, also on P2002; reserved slugs
  `categories|feed|sitemap`), patch (slug immutable → 422; publish without date = now; drafts keep
  their date; `read` recomputed when `body` given), delete → 204. `queueEntityTranslation` after
  create/patch. Exports for WP-07: `block`, `photoInput`, `seoText`, `readTime`, `isImageSrc`,
  `createSchema`, `patchSchema`, `postsKeyset`.

### Storefront (SSR, `prerender = false`)
- `src/pages/journal/index.astro`, `journal/category/[category].astro`, `journal/[slug].astro`
  with 200 / 404 (`noindex`) / 503 (`Retry-After`) states, Base SEO props, Article JSON-LD.
- `src/components/journal/`: `FeaturedPost`, `PostCard`, `PostRow`, `CategoryChips`, `PostBody`
  (zero JS, used by WP-07), `ShareActions` (share / copy link / print), `headings.ts`
  (`headingsOf`, `headingIds`, `quoteText`), `seo.ts` (`clip`, `shareImage`, `articleJsonLd`),
  `shared.ts`, `parts.tsx` (breadcrumb, state block, newsletter island). Locale JSON unchanged.

### Dashboard (`src/portal/screens/journal/`, `src/portal/queries/journal.ts`)
- `JournalList`: Published/Drafts view (SegmentedControl), debounced search, category select,
  clear filters, sortable Published/Updated headers, selection + kit `BulkBar` (publish / move to
  drafts / delete, partial counts, confirm lists the rows), row `Menu` (edit, view on store when
  live, duplicate as draft, publish / move to drafts, delete), `LoadMore`, loading/empty/error.
- `PostEditor` (`NewPost`, `EditPost`): VAREL's full-page editor — Details, Publishing, Body
  (`BlockEditor`), kit `SeoPanel`, live `Preview` (side by side ≥1280px, Write/Preview toggle
  below), Save draft / Publish / Schedule / Move to drafts / Save changes with per-button pending,
  Ctrl/Cmd+S, client rules = server rules (same dotted keys), server 422/409 on their fields,
  413 → "too long (64 KB)" status line, leave guard (`useBlocker` + kit confirm + beforeunload),
  author defaults to the signed-in name. `EditPost`: skeleton, "Post not found", error + retry.
- `ImageSource` (single image: URL, upload via kit `uploadImage`, remove), `BlockEditor`
  (`fixed` supported), `Preview` / `PreviewBody`, `form.ts` (`EditorBlock`, `emptyBlock`,
  `blockFromPost`, `blockToPost`, `FieldErrors`, `validate`…) — all exported from `index.tsx` for WP-07.
- `screen.css` (`.screen-journal`, `.post-preview*`), tokens only.

## Differences from VAREL
- Keyset pages + "Load more" instead of page numbers; list header shows "25+ posts" (no count).
- Public list capped at 100 posts (VAREL loaded all); categories counted within the 100 newest.
- Unknown category page answers 404 + noindex (VAREL: 200 empty state).
- Reserved slugs `categories`, `feed`, `sitemap`; 64 KB body limit message in the editor.
- Server limits follow the F1 columns and VAREL's client copy (category ≤60, author ≤80, excerpt ≤320).
- Image sources: `https://`, `/site-api/media/` or `/__platform/files/` (kit uploads).
- Row click does not open the editor (the title is the link); kit `DataTable` has no row click.
- "Copied as a new draft" toast has no "Open" action (kit toasts have no actions); it names the copy.
- Status picker is a `SegmentedControl` (VAREL's two-button radio), preview title is a `<p>`
  (the portal keeps one `<h1>`).
