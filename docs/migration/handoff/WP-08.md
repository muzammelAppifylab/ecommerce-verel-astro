## Differences from VAREL (deliberate)

- `?q=` result pages are `noindex` (thin generated pages); bare `/search/` stays indexable. Canonical is the template's.
- Result caps: products, categories and posts each ≤ 100 (`SEARCH_LIMIT`); products are additionally bounded by F4 `CATALOG_LIMIT`. No paging (one bounded answer).
- API `Cache-Control: private, max-age=30` (answer depends on locale).
- Category counts come from the loaded published product list, not `_count` (no `count()` per request).
- Category hits carry `deptSlug` / `categorySlug` (F3 type already has them); links use them, falling back to `slugify(name)`.
- `q` over 200 chars: API 422 `invalid_input` with `fields.q`; the page clips to 200 so a hand-typed URL never shows an error; input `maxLength=200`.
- Analytics `query` lowercased and clipped to 120 chars (the events validator's cap).
- History via `history.replaceState/pushState(history.state, …)` instead of TanStack Router.
