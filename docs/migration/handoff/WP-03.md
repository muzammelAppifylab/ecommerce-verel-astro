## Differences from VAREL

- `<title>` is Base's `"{seoTitle ‖ name} · {site name}"` (VAREL `"{name} — {store}"`); `og:type` is `website`
  (Base allows no `product`). See Requests.
- Accordion: native `<details>` (no JS) instead of React state; in browsers without `<details name>` several
  panels can be open at once.
- Add to bag: `disabled` + `aria-busy` + dimmed while pending (AGENTS.md), label unchanged (VAREL look).
- Analytics uses a local `track` until WP-16's beacon exists.
- Non-palette custom colours in the description are only painted by F2's RichText after hydration; the static
  Details panel drops them (palette colours are classes and stay).
- Related ordering ties break on `id`, not `name` (F4's `allProducts`; seed positions are distinct).
- Related can come back shorter than `limit` when `hideSoldOut` drops many products (bounded reads).
