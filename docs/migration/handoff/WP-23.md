# WP-23 · Store settings: hand-off

Branch `wp/WP-23` (from `wave0`). Owns `src/server/routes/admin/{settings,tax-rates,shipping,payments}.ts`,
`src/portal/queries/settings.ts`, `src/portal/screens/settings/**` (except `emails/`, `languages/`),
`tests/settings-rules.test.ts`, `tests/integration/admin-{settings,tax-rates,shipping}.test.ts`.

## What was ported

### Server (`/site-api/manage/*`, guarded centrally by F3's `MANAGE_AREAS`)
- `settings.ts`: `GET /settings` (`getSettings` + `ownerSecretFlags()`), `PATCH /settings` with the
  exported `settingsPatch` zod schema (every VAREL field, `.partial()`, unknown keys and `secrets`
  stripped). Cross-checks: default locale must be enabled (default sorted first; error on `locales` or
  `defaultLocale`, whichever was sent); `paymentProvider: 'stripe'` needs a publishable key.
  `freeShippingThreshold` → `free_shipping_threshold_cents`; `socialLinks`/`emailConfig`/`homeHero`
  replace the stored object (`homeHero: {}` clears it, empty `emailConfig` values dropped). After a
  write: `setStoreCurrency`, `setOrderPrefix`, and `invalidateLocaleSettings()` when locales changed.
  `{}` answers the current settings without a write.
- `tax-rates.ts`: list (sorted by country, `take 100`), create (201, `name` defaults to `VAT`,
  country canonical-cased, 409 `country_taken` with `fields.country`, also on a P2002 race), patch,
  delete (204). Int ids on the wire as strings; a non-numeric or unknown id answers 404.
- `shipping.ts`: zones + methods (VAREL's 7 endpoints). One country in one zone (`countries.N` field
  errors, "Sweden is already in European Union"), exactly one catch-all (422 on a second, 409
  `last_catch_all` on emptying/deleting the last one), slug ids made once (`nordics`, `nordics-2`,
  `nordics-express`) with ONE bounded `startsWith` read, zone writes in a transaction, delete cascades
  methods, rates in units on the wire / cents in the DB. Local `adminZone`/`adminMethod` serializers.
- `payments.ts`: `GET /payments/status` (requires `STORE_SETTINGS_MANAGE`): `active` (stripe only with
  secret key + valid pk + provider stripe), `selected`, key flags and modes, webhook URL from
  `config.siteUrl` (fallback request origin) + `/site-api/webhooks/stripe`, events list,
  `apiHostOverride: false`. Never returns a key value. Local `keyMode`, `STRIPE_WEBHOOK_PATH`,
  `STRIPE_WEBHOOK_EVENTS` until WP-11 is merged.

### Portal
- `queries/settings.ts`: F5's `SettingsSection`, `SettingsAbility`, `SettingsNavItem`, `SETTINGS_NAV`,
  `loadSettings` kept; added `settingsKeys`, `settingsQuery`, `taxRatesQuery`, `shippingQuery`,
  `paymentsStatusQuery`, `updateSettings`, `useUpdateSettings`, tax-rate / zone / method mutation hooks.
- `screens/settings/shared.tsx` (public kit for WP-04/07/16/22/24/25): `useCanEditSettings`,
  `firstProblem`, `SETTINGS_DEFAULTS`, `withDefaults`, `SettingsCodec`, `diff`, `useSettingsDraft`,
  `SettingsShell` (`embedded` too; save state, Discard/Save pending, sticky save bar, ⌘S, leave guard
  on route change and tab close, read-only `fieldset disabled` + `ReadOnlyNote`, loading/error/403
  states), `Section`, `ToggleRow`, `fieldAria`, `isEmail`, `isWhole`, `isAmount`, `isUrl`,
  `toPercent`, `fromPercent`, `currencySymbol`.
- `limits.ts`: `SETTINGS_LIMITS` + link/key/prefix regexes, imported by BOTH the route and the screens
  (client rules = server rules).
- Screens (each a VAREL page, same sections, fields and copy): `general.tsx` (+ `LogoField`),
  `checkout.tsx`, `payments.tsx`, `tax.tsx` (+ `WorkedExample`), `tax-rates.tsx` (`CountryRates`,
  saves immediately, Modal editor, `useConfirm` delete), `inventory.tsx` (+ `ReasonsEditor`),
  `privacy.tsx`, `seo.tsx` (+ `SearchPreview`, link preview, `ImageLinkField`), `shipping/`
  (`index.tsx`, `ZoneCard.tsx`, `dialogs.tsx` with `ZoneModal`/`MethodModal`/`isCatchAll`/`zoneLabel`,

- `screen.css`: the settings styles (tokens only, light + dark), bundled by `App.astro`'s glob.

## Differences from VAREL
- Limits reconciled to one set (spec §3.2): announcement 160, terms 500, low stock ≤ 1000, return
  window ≤ 365, ≤ 12 return reasons, order prefix ≤ 10 and must end in a non-digit; phone pattern
  checked on the server too; `emailConfig` ≤ 10 keys with an https `endpoint`.
- Image links (`logoUrl`, `ogImage`) are https or a site path only (no `http://`, no `//host`).
  Logo/share image upload goes through F5 `uploadImage` (platform files, WP-17's route): JPEG/PNG/WebP/
  AVIF up to 8 MB; SVG/GIF no longer accepted. Pasting a URL still works while uploads answer 501.
- Social links: full web links only (VAREL's server also accepted `/paths`).
- `queueEntityTranslation` after settings and shipping-method writes is dropped: WP-25's hourly
  backfill picks them up.
- Payments copy names owner secrets (`STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`), not Worker
  secrets / wrangler / `.dev.vars`; no `STRIPE_API_HOST`.
- Visibility (spec §8.1): F5's `SETTINGS_NAV` hides every section but General from staff without
  `manageStoreSettings`; VAREL showed them read-only. Server reads stay open to any staff. `ro` is
  implemented everywhere anyway.
- Currency/prefix module state is per isolate (F4); public settings are cached ≤ 60 s by WP-01.
