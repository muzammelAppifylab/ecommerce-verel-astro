## Differences from VAREL

- `/pages/privacy/` and `/pages/terms/` answer **301** to `/privacy/` and `/terms/` (VAREL served duplicates).
- Contact page keeps VAREL's `mailto:` design; the `POST /site-api/contact` route exists (F3 contract) but no page form uses it yet, and it sends no staff alert (VAREL has no template).
- Local copies kept so this package does not wait on others (keep them equal): journal `PostBody` render in `src/components/pages/PageBody.tsx` and `src/portal/screens/pages/PagePreview.tsx`; block editor (`BlockEditor.tsx`, `blocks.ts`) in `portal/screens/pages/`; `DEFAULT_HERO`/`resolveHero` in `portal/screens/navigation/hero.ts` (storefront copy is WP-01's).
- Page/dashboard visual styles live in `src/portal/screens/pages/screen.css` (kit classes elsewhere).
