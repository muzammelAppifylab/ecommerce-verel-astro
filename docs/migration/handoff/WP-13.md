## Differences from VAREL

- **Delete account**: the template deletes the sign-in. `POST /site-api/account/delete {password, confirm:'DELETE'}`
  checks staff first (any role other than `member` → 409 `staff_account`, VAREL words), collects ids of orders /
  reviews / redemptions linked to the account, calls the template's `POST /site-api/auth/delete-account`
  **in-process** (its 401/409/422/429 pass through untouched), then masks the linked rows, runs F4
  `anonymiseCustomer`, sends `account_deleted` via `sendTemplate`, and returns the template's 200 with
  `visitor_id` cleared. A new typed "DELETE" field is in the dialog (template rule). Answer is 200, not 204.
- **Password**: template `POST /site-api/auth/change-password` (10–128, not the email name; signs other devices out).
  One show/hide button per field (AGENTS) instead of VAREL's "Show passwords" checkbox. Accounts without a password
  (code sign-in) see "Set a password" → `/account/forgot/`.
- **Email**: no longer edited in the profile form; read-only row + "Change email" dialog → template
  `POST /site-api/auth/email` (202, confirmation link; no `EMAIL_TAKEN`).
- **Downloads**: private platform files; the screen asks for JSON through `siteFetch` then navigates (Preview-safe),
  per-row pending + error. VAREL's `products.download` product check is dropped (no index; buyers keep access).
- **Forms**: errors on blur/submit then live, focus first wrong field, server `fields` on their fields, pending
  buttons with spinner + `aria-busy`, Cancel disabled while pending (AGENTS rules; VAREL validated on submit only).
- A `returning` visitor (access token expired, refresh cookie present) gets the app, not a redirect; its first
  siteFetch renews the session. Only a guest is redirected to sign in.
- Sign-out sits in the desktop menu as in VAREL; it goes to `/account/login/` with a full load.
- Address city ≤ 100 (F1 column). Addresses are bounded at 50.
- Locale JSON: `password.rule` / `password.errors.length` now say 10 characters; new keys (all 6 locales):
  `password.{showOne,hideOne,noPassword,setLink}`, `password.errors.{tooLong,email}`,
  `profile.{emailHint,changeEmail}`, `profile.errors.{firstNameLong,lastNameLong,phoneLong}`, `email.*`,
  `dialog.errors.tooLong`, `privacy.delete.{confirmLabel,errors.confirm}`, `downloading`, `downloadError`,
  `ordersMore`, `notFound.{title,action}`, `ordersComingSoon`.
