Cross-package contract (`cart-store.ts`, `actions.ts`): as in the prep spec §7.1. Every server cart is reported to
F2's `bag.applyCart(cart)` (header count + `varel:cart` event); carts other islands report there land in the cache.
`addToBag` fires `varel:add-to-bag` (`ADD_TO_BAG_EVENT`, detail `{productId, variantId, qty}`) for WP-16's tracker.

## Differences from VAREL (deliberate)

- **B1 Read-only GETs**: `GET /cart` and `/cart/totals` create no cookie, `Visitor` or `Cart`; a visitor without a
  bag reads an empty bag with `id: ''` (real threshold, tax name, labels). Writes create the `visitor_id` cookie.
- **B4 Lazy guest → account merge**: every cart route, signed in with a guest `visitor_id` that owns a bag or
  wishlist rows, calls F4 `mergeGuestIntoUser` first (template sign-in has no hook).
- **B9 Bound**: 100 distinct lines (`BAG_FULL` 409 from F4 `addLine`); recovery reads ≤ 100 lines.
- `robots.txt` `Disallow: /cart` dropped: the page is `noindex` and excluded from the sitemap (F3's `EXCLUDE`).
- Line ids are integers; malformed / out-of-range ids answer the same 404 as an unknown line.
- Recovery redirects to `/cart/` (trailing slash), always `no-store`; failures are logged and still redirect.
- Links are plain `<a href>` with locale prefixes (`src/lib/links.ts`) instead of TanStack `<Link>`.
- Remove buttons: only the acted-on row is pending, other rows' remove disabled (AGENTS buttons).
- `TotalLine` takes `size: 'md' | 'lg'` instead of an inline font size.
