## Differences from VAREL
- Save path no longer translates in the request: one background job per save; the hourly schedule
  (`background.json`, `translations-backfill`) covers anything a rejected job missed.
- `translate-missing` does 20 field-locales / 20 s / 120 provider strings per request (VAREL 150 / 25 s);
  the client loops (≤200 calls) until `remaining === 0` or a batch translates 0. Status polls every 4 s while it runs.
- No retry sleeps; 429 counts as failed and is retried later.
- `GET /i18n/catalog/:locale/:ns` dropped (islands get dictionaries as props; see R4).
- Add language offers only routable codes (`labels.ts` `ROUTABLE_LOCALES`), not a free code input (R3).
- Long/rich/JSON fields edit in a `Drawer` with `TranslationEditor` instead of an expanding row;
  pagination is keyset + `LoadMore`.
- Rich source column in the editor shows plain text (`richToPlain`), not formatted rich text (F5).
